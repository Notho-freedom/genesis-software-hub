## Project info

This repository contains the Genesis Software Hub web application. It is currently maintained through a Lovable-compatible workflow while remaining editable from a local development environment or GitHub.

## 🛠️ Stack

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## 🚀 Local development

```bash
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## ✏️ Editing

The project can be edited through Lovable, a local IDE, GitHub, or GitHub Codespaces. Changes pushed to the repository can be reflected in the connected development workflow.

## 🚀 Deployment

Deployment is currently compatible with the Lovable publishing workflow. A custom domain can be connected through the project's hosting configuration.
